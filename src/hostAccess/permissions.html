OldLander needs access to reddit

Firefox hasn't given OldLander permission to run on reddit.com, so it can't restyle old reddit. This can happen after an update, because Firefox doesn't grant new site access on its own.

If the button doesn't work, open Firefox's add-on settings, choose OldLander, and turn on its permission for reddit.com.
